# easy-pocket-money

## Was kann man mit Easy Pocket Money tun?

- Taschengeld verwalten
- Nutzer anlegen, Rollen verwalten (Eltern und Kinder)
- Eltern bestimmen wie viel Taschengeld die zugeordneten Kinder bekommen
- Taschengeld wird als "Konto" verwaltet
- Neues Taschengeld wird dem Konto automatisch gutgeschrieben
- Waehrung kann eingestellt werden
- Kinder koennen Ausgaben erfassen (z.B. wenn sie sich Spielzeug oder Suessigkeiten gekauft haben)
- Kinder sehen die Entwicklung ihres Taschengeldes, und koennen sehen, wie sich ihr Konto in der Zukunft entwickeln wird
